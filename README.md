# Customer_Behaviour_Analysis

## Overview
This project focuses on analyzing customer behaviour using Python, PostgreSQL, and Power BI. The dataset was cleaned, explored, stored in a PostgreSQL database, analyzed using SQL queries, and visualized through an interactive Power BI dashboard. A project report and presentation were also created to summarize the findings.

---

## Dataset
- Customer Behaviour Dataset
- Source: CSV file
- Contains customer demographic and behavioural information used for analysis.

## Project Workflow

### 1. Data Loading
- Imported the dataset into Python.
- Loaded the cleaned data into PostgreSQL using SQLAlchemy.

### 2. Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Corrected data types.
- Prepared data for analysis.

### 3. Exploratory Data Analysis (EDA)
- Explored customer demographics.
- Identified trends and patterns.
- Generated summary statistics.

### 4. SQL Analysis
- Wrote SQL queries in PostgreSQL.
- Performed filtering, grouping, aggregation, and analysis.

### 5. Power BI Dashboard
Created an interactive dashboard including:
- Customer Overview
- Sales Analysis
- Customer Segmentation
- Key Performance Indicators (KPIs)
- Interactive Filters

### 6. Documentation
- Project Report
- PowerPoint Presentation (Created using Gamma)

6. Import the cleaned data into PostgreSQL.
